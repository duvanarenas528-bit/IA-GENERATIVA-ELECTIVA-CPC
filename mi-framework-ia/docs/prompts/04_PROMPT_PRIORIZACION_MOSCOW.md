# Prompt · Priorización MoSCoW

## Objetivo
Priorizar las historias de usuario (incluidas las auditadas y las que el equipo agregó) usando el método MoSCoW (Must have, Should have, Could have, Won't have).

## Prompt utilizado

```
Actúa como Product Owner. Toma la siguiente lista de historias de usuario
(incluyendo las que el equipo identificó como faltantes tras la auditoría)
y clasifícalas usando el método MoSCoW: Must have, Should have, Could have,
Won't have (this time).

Para cada historia, indica la categoría y una justificación breve de por qué
se ubicó ahí, considerando que es un proyecto académico con tiempo y
recursos limitados, y que el análisis con IA es el diferenciador principal
del producto.

Historias:
[pegar contenido de 03_HISTORIAS_USUARIO.md]
```

## Notas de uso
- Se usó como entrada la lista completa de 7 historias generadas por IA más las 3 historias adicionales identificadas en la auditoría humana (10 en total).
- El resultado de esta priorización alimenta directamente el Product Backlog (`DOC/05_PRODUCT_BACKLOG.md`).
