# Prompt · Extracción de requerimientos

## Objetivo
A partir de la transcripción de la entrevista, obtener una frase de requerimiento en lenguaje del cliente y una lista de requerimientos funcionales y no funcionales.

## Prompt utilizado

```
Actúa como analista de requisitos de software. A partir de la siguiente
transcripción de entrevista con el cliente, haz dos cosas:

1. Redacta el requerimiento principal en UNA sola frase, tal como lo diría
   el cliente/usuario real, sin jerga técnica.

2. Extrae una lista de requerimientos funcionales (RF) y no funcionales (RNF)
   del sistema, numerados, en español, redactados de forma clara y verificable.

Transcripción:
[pegar contenido de 01_TRANSCRIPCION.md]
```

## Notas de uso
- La frase de requerimiento resultante se usó directamente en la Parte 1 del taller.
- Los RF/RNF sirvieron de base para redactar las historias de usuario del paso siguiente.
