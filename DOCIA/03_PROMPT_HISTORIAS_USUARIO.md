# Prompt · Generación de historias de usuario

## Objetivo
Generar al menos 5 historias de usuario con criterios de aceptación, siguiendo el formato de la demostración (Diapositiva 08), a partir de los requerimientos funcionales.

## Prompt utilizado

```
Actúa como Product Owner. A partir de los siguientes requerimientos
funcionales, redacta al menos 5 historias de usuario en el formato:

Como [rol],
quiero [acción],
para [beneficio].

Cada historia debe incluir de 3 a 5 criterios de aceptación verificables,
en formato de lista. No agregues explicaciones adicionales fuera del
formato solicitado.

Requerimientos funcionales:
[pegar contenido de 02_REQUERIMIENTOS.md, sección RF]
```

## Notas de uso
- Se obtuvieron 7 historias de usuario (más de las 5 mínimas solicitadas).
- El resultado se auditó de forma crítica en el paso de Parte 3 del taller (ver `DOC/03_HISTORIAS_USUARIO.md`).
